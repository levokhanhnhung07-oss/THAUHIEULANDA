
# L'AURA DIGITAL

Consumer Insight & Personalized Marketing website built with Streamlit.

## Features

- Consumer problem recognition
- Active and inactive problem classification
- Customer context and preferences
- Rule-based recommendations
- Optional OpenAI API integration
- Customer insight report export
- Marketing event tracking

## Run locally

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the app:

```bash
streamlit run app.py
```

## Enable OpenAI API

Set your API key as an environment variable.

Windows PowerShell:

```powershell
$env:OPENAI_API_KEY="YOUR_API_KEY"
streamlit run app.py
```

Never upload your API key to GitHub.
